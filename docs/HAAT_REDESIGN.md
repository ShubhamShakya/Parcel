# Haat-inspired Parcel UI

The supplied Haat HTML is a visual reference. Parcel retains its name, local simulation, authentication, address editing, payment safeguards, persistent orders, unboxing and shelf.

## Implemented

- Sage background, navy controls, amber offers, white rounded surfaces and bundled Albert Sans (SIL Open Font License).
- Home delivery-address shortcut, illustrated category shortcuts, Men/Women tiles, horizontal featured finds, active-order shortcut and sorting by rating or price.
- Product-card discount badges, comparison pricing and quick add (clothing opens variant selection).
- Persistent Add to cart / Buy now bar; Buy now adds the selected variant successfully before opening cart review.
- Persistent cart total/checkout and checkout total/confirmation bars, retaining acknowledgement and payment gating.
- Illustrative Delhi delivery map driven by the existing persistent order timeline; the marker reaches the destination on delivery. No GPS or real rider is implied.
- Account links to orders, editable addresses and the purchased collection. Logout confirmation remains.

## Not included in this pass

Dark mode, a notification inbox, support/chat/call flows, returns, real sharing, a coupon browser and manual coupon entry remain separate work. No nonfunctional buttons for these were added. Existing offers remain automatically applied when eligible; there is no artificial expiring-deal timer.
